🟢 Способ 1. Полный автомат через браузер (0 настроек, без Docker)
1. Просто войди в свой аккаунт на gemini.google.com в этом браузере.
2. Нажми синюю кнопку «⚡ Авто-подключение через вкладку Gemini» выше.
3. Всё! Расширение само найдёт вкладку с чатом Gemini, подхватит куки и будет делать разбор состава и КБЖУ прямо через неё. Если дополнительно запустить start_server.bat — оно ещё и подтянет живые отзывы с Отзовика/IRecommend!
🚀 Способ 2. Через локальный мост Gemini 4 Argon (:8083 из твоего гайда)
Шаг 1. Запусти Docker Desktop и выполни в PowerShell команду запуска моста:
Шаг 2. Нажми кнопку «🍪 Скопировать куки Gemini без F12» выше (расширение само достанет Header String из браузера, ставить Cookie-Editor не нужно!).
Шаг 3. Открой админку http://localhost:8083/admin/:
• В Accounts -> Quick Add Cookie вставь скопированные куки.
• В Settings выбери модель gemini-4-argon, включи Auto-follow bl version (ВКЛ) и 临时对话 / Временный чат (ВКЛ), а 服务端多轮续接 (ВЫКЛ).
• Скопируй API Key в правом верхнем углу админки, вставь в поле API Key ниже и нажми «Сохранить».
Шаг 4. Запусти start_server.bat в папке расширения для поиска отзывов по Отзовику и кэша SQLite.
Быстрый выбор ИИ-провайдера (для моста :8083 или API):
