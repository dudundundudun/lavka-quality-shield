## 🔥 Главные козыри версии v2.5.0 (ПОЛНЫЙ АНТИ-ШУЛЕР И МУЛЬТИ-АККАУНТ КОМБАЙН!)

### 1. 🔐 Менеджер Аккаунтов Лавки: Куки-Сессии + Логины и Пароли (Переключение в 1 клик!)
* **Мгновенная смена аккаунта по куки (`⚡ Переключить вход в 1 клик`)**: расширение сохраняет полную сессию авторизации (`.yandex.ru`, `lavka.yandex.ru`, `Session_id`, `sessionid2`, `yandex_login` и `localStorage` адреса) в локальный сейф (`lqs_accounts_vault_v1` + SQLite `:8765`). Переключайся между аккаунтами за 0.5 секунды без ввода пароля и СМС!
* **Встроенный сейф логинов и паролей (`🔑 Пароль ▾`)**: сохраняй логин/телефон, пароль (с кнопкой просмотра `👁️` и копирования `📋`) и заметку для каждого профиля.
* **Авто-вход на Яндекс ID (`passport.yandex.ru` / `id.yandex.ru`)**: если сессия истекла или ты входишь в новый аккаунт, плавающая панель на странице входа сама подставит логин и пароль выбранного профиля в 1 клик!
* **Быстрый переключатель прямо в корзине (`👤 Сменить аккаунт ▾`)**: кнопка **`🚀 Переключить и собрать эти N шт.`** сама сохраняет текущую корзину, меняет куки на другой аккаунт и автоматически собирает всю корзину!

### 2. 🏪 Радар Конкурентов и Выпадающий Список Магазинов прямо в Корзине (`/cart`)
* Прямо в шапке корзины (`🛡️ Анти-Шулер Аудит Корзины`) расширение автоматически проверяет все позиции корзины и сразу выводит:
  * **Суммарную переплату относительно других сетей**: `🏪 У конкурентов дешевле (N поз.): переплата +X ₽!`
  * **Суммарную переплату относительно Гостя (без куки) и других твоих аккаунтов**: `🕵️ Без куки / на др. акке дешевле на -Y ₽!`
* **Выпадающий список по кнопке `🏪 Магазины и переплата ▾`**: раскрывает детальную карточку по каждому товару корзины с найденными ценами конкурентов и **прямыми кликабельными ссылками** на этот товар в **Перекрёстке, ВкусВилле, Ozon, Яндекс Маркете, Ленте и Купере**!

### 3. 🚀 Исправленный Авто-Сборщик Корзины (Точность 8 из 8 единиц!)
* **Точный подсчёт позиций и штук (`поз. / шт.`)**: исправлена ошибка, из-за которой при переносе корзины из 8 единиц собиралось только 6.
* **Поддержка SVG-степпера `«- N +»`**: авто-сборщик теперь находит правую кнопку `+` внутри степпера Лавки (даже когда внутри кнопки только SVG-иконка без текста `+`), контролирует фактическое число на счётчике и дожимает ровно нужное количество штук по каждой позиции + делает автоматический повторный проход (`Retry Pass`) при медленной загрузке!

### 4. ✨ Идеально ровный интерфейс на карточке товара (UI Fix)
* Устранено наложение строк в заголовке ИИ-блока (`.lqs-ai-header`) и исправлена кнопка сохранения заметки (`💾 Ок`) — никакие стили Яндекс Лавки больше не ломают высоту строк и кнопок.
