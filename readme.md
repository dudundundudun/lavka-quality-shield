# ❤️⭐ Lavka Quality Shield v2.2.0 (Автопилот ИИ + Бортовой самописец)

Расширение для Chrome (**Manifest V3**) на сайте **Яндекс Лавки** (`https://lavka.yandex.ru/*`) с собственным рейтингом товаров, расчётом честной цены за 1 кг/л и 100 г белка, защитой корзины от случайной покупки «бана» и **автоматическим подключением к твоему Google Gemini**.

---

## 🤖 Два способа подключить ИИ (от полного автомата за 5 секунд до Docker-моста `:8083`)

### 🟢 Способ 1. Полный Автопилот через открытую вкладку браузера (0 настроек, без Docker и без F12)
Расширение теперь умеет само находить открытую вкладку с чатом `https://gemini.google.com/` и общаться с ней напрямую через твои куки в браузере:
1. Убедись, что ты вошёл в свой аккаунт на [https://gemini.google.com/](https://gemini.google.com/).
2. Нажми на иконку **Lavka Quality Shield** в правом верхнем углу браузера -> вкладка **«⚙️ Настройки и ИИ»**.
3. Нажми синюю кнопку **«⚡ Авто-подключение через вкладку Gemini (1 клик)»**.
4. Готово! Два верхних индикатора (`🌐 Вкладка Gemini` и `🍪 Куки Google`) загорятся зелёным. Теперь при нажатии **«🤖 ИИ-обзор»** на странице любого товара в Лавке расширение само отправит состав, цену и КБЖУ в твой Gemini и выведет вердикт в карточке товара!
   - *Бонус*: Если параллельно запустить `start_server.bat`, то локальный сервер (`:8765`) сначала спарсит живые отзывы с Отзовика/IRecommend/Роскачества, передаст их во вкладку Gemini и сохранит готовый ответ в базу `lavka_ai_cache.db`!

---

### 🚀 Способ 2. Локальный мост `gemini-4-argon` через Docker (`http://localhost:8083`) — куки копируются в 1 клик без F12!
Если ты используешь локальный контейнер `ghcr.io/zexadev/gemini-web2api-go:latest` из своего гайда (чтобы не держать вкладку Gemini открытой):
1. Запусти **Docker Desktop**, открой **PowerShell** и выполни команду (её также можно скопировать в 1 клик прямо внутри настроек расширения):
   ```powershell
   docker run -d --name gemini-argon --restart unless-stopped -p 8083:8083 ghcr.io/zexadev/gemini-web2api-go:latest; Start-Sleep -Seconds 2; Write-Host "🚀 Сервер запущен! Админка: http://localhost:8083/admin/" -ForegroundColor Green
   ```
2. Открой окно расширения **Lavka Quality Shield -> ⚙️ Настройки и ИИ** и нажми кнопку:
   **«🍪 Скопировать куки Gemini (Header String) без F12»**
   *(расширение само считает `__Secure-1PSID`, `__Secure-1PSIDTS` и `SID` напрямую из браузера и положит готовый `Header String` тебе в буфер обмена — ставить Cookie-Editor не нужно!).*
3. Открой админку моста [http://localhost:8083/admin/](http://localhost:8083/admin/):
   - Перейди в **Accounts -> Quick Add Cookie** и вставь скопированные куки (`Ctrl + V`).
   - Перейди в **Settings (Настройки)**:
     - **Default model**: `gemini-4-argon`
     - **Auto-follow bl version**: ✅ **ВКЛ**
     - **临时对话 (Временный чат)**: ✅ **ВКЛ** (чтобы запросы расширения не засоряли твою историю чатов Gemini)
     - **服务端多轮续接 (Серверное продолжение)**: ❌ **ВЫКЛ**
   - В правом верхнем углу админки нажми **Copy API Key**, вставь его в поле **API Key** в настройках расширения и нажми **«💾 Сохранить настройки ИИ»**.
4. Запусти `start_server.bat` для автоматического парсинга Отзовика/IRecommend и кэширования ответов в SQLite.
