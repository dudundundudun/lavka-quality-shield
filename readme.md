## ⚡ Установка и запуск за 10 секунд (ПРОЩЕ НЕ БЫВАЕТ!)

### Вариант А. Полный Zero-Click Автомат прямо в браузере (Без Python и без Docker)
1. Распакуй архив `lavka-quality-shield-v2.3.0.zip` в любую постоянную папку.
2. Открой `chrome://extensions`, включи **Режим разработчика (Developer mode)** в правом верхнем углу и нажми **«Загрузить распакованное расширение» (Load unpacked)** -> выбери папку проекта.
3. Убедись, что ты один раз вошёл в свой аккаунт на [https://gemini.google.com/](https://gemini.google.com/).
4. **ВСЁ! Иди на [https://lavka.yandex.ru/](https://lavka.yandex.ru/) и просто открывай товары!** Расширение само прогреет Gemini в фоне, само спарсит отзывы, само напишет вердикт и само запомнит результат.

---

### Вариант Б. Тихий автозапуск локального сервера (`:8765`) и Docker-моста (`:8083`) вместе с Windows
Если ты хочешь максимальную скорость через локальный FastAPI-сервер `server.py` (`127.0.0.1:8765`, база `lavka_ai_cache.db`) и контейнер `gemini-web2api-go` (`localhost:8083`), но **не хочешь каждый раз запускать батники вручную**:

1. **Запусти один раз `enable_windows_autostart.bat`** (двойным кликом).
   - Скрипт автоматически установит зависимости Python, пропишет скрытый VBS-ланчер в автозагрузку Windows (`shell:startup`) и сразу запустит `pythonw -B server.py` и Docker-контейнер `gemini-argon` **в фоновом режиме без единого чёрного окна консоли**!
   - Чтобы отключить автозапуск в любой момент — просто запусти `disable_windows_autostart.bat`.
2. Если настраиваешь Docker-мост `gemini-4-argon` (`:8083`) впервые:
   - Выполни в PowerShell (копируется в 1 клик в настройках расширения):
     ```powershell
     docker run -d --name gemini-argon --restart unless-stopped -p 8083:8083 ghcr.io/zexadev/gemini-web2api-go:latest
     ```
   - В окне расширения открой **«⚙️ Настройки и ИИ»** и нажми **«🍪 Скопировать куки Gemini (Header String) без F12»**.
   - Вставь скопированную строку в админку [http://localhost:8083/admin/](http://localhost:8083/admin/) (`Accounts -> Quick Add Cookie`), включи `Auto-follow bl version` и `临时对话` (Временный чат), скопируй `API Key` и сохрани его в настройках расширения.

## 📁 Структура проекта

- `manifest.json` — конфигурация Chrome Extension (Manifest V3).
- `background.js` — фоновый оркестратор Zero-Click Автопилота, очередь запросов к вкладке Gemini, парсер DuckDuckGo и браузерный кэш ИИ (`lqs_ai_cache_v1`).
- `content.js` — инжектор однострочной панели Лавки, калькулятор цены за кг / 100 г белка, автозапуск ИИ при открытии товара, разметка каталога и защита корзины.
- `popup.html` / `popup.js` — менеджер личной базы оценок, переключатели Zero-Click Автопилота, мульти-аккаунт селектор Gemini (`/u/0..4`), 1-клик экстрактор куки и бортовой журнал.
- `server.py` — опциональный локальный FastAPI-сервер (`127.0.0.1:8765`) с кэшем SQLite (`lavka_ai_cache.db`).
- `enable_windows_autostart.bat` / `disable_windows_autostart.bat` — установка и удаление тихого фонового автозапуска серверов при старте Windows.
- `start_server.bat` — ручной запуск локального FastAPI-сервера с консолью.
