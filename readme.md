# 🛡️ Lavka Quality Shield v2.5.2 — Exact Product Match, Zero-Freeze AI, Account Switcher & Cart Audit

Гибридное расширение **Google Chrome (Manifest V3)** и локальный сервер **FastAPI + SQLite (`127.0.0.1:8765`)** для защиты покупателя на сайте **Яндекс Лавки (`https://lavka.yandex.ru/*`)**.

---

## 🔥 Что исправлено и улучшено в релизе v2.5.2

1. **🎯 100% Точный поиск идентичных товаров у конкурентов (Exact Product & Modifier Matcher)**:
   - **Никакой путаницы «Колы без сахара» с обычной «Колой»**: внедрён строгий фильтр модификаторов (`SUGAR_FREE_REGEX` и `FLAVOR_AND_TYPE_MODIFIERS`). Если товар содержит маркер **«без сахара» / «Zero» / «Light»**, поисковик запрашивает точную фразу `"без сахара"`, а парсер жёстко отсекает любые результаты с обычной сахарной версией (и наоборот).
   - **Сохранение полного названия и объёма/веса (`1,5 л`, `2 л`, `175 г`)**: функция `buildFullProductSearchQuery` больше не обрезает литраж и граммовку в конце названия, а в корзине автоматически склеивает название товара с его фасовкой. При проверке цен конкурентов результаты с другим объёмом (например, баночка `0,33 л` вместо бутылки `1,5 л`) отфильтровываются.
   - **Прямые кнопки магазинов прямо на карточке товара**: теперь кнопки мгновенного поиска полного названия товара в **Ozon, Перекрёстке, ВкусВилле, Яндекс Маркете, Ленте и Купере** доступны не только в корзине, но и прямо внутри карточки товара в блоке Радара цен.

2. **⚡ Устранение зависания окна ИИ («НЕ ОБНОВЛЯЕТСЯ ОКНО») и ошибки `message channel closed before a response was received`**:
   - **Keep-Alive пинг Service Worker'а (`startSwKeepAlive`)**: удерживает фоновый воркер Chrome Manifest V3 активным во время генерации ответа во вкладке Gemini.
   - **Push-доставка (`LQS_AI_VERDICT_READY`) + реактивная подписка на `AI_CACHE_KEY`**: карточка товара мгновенно обновляет блок ИИ-разбора при записи ответа в `chrome.storage.local` или при пуше от фонового воркера, даже если исходный канал `sendMessage` закрылся.
   - **Авто-отмена устаревших задач в очереди Gemini**: если пользователь быстро перешёл с одного товара на другой, старые фоновые задачи не блокируют очередь `geminiTabMutex`.

3. **🔗 Единая связка двух типов URL одного товара в Лавке (SEO-slug ↔ HEX-ID)**:
   - В каталоге Лавка использует человекочитаемый адрес (`/good/napitok-cola-dobryj-bez-sahara-15-liter`), а при переходе из корзины `/cart` — 44-символьный внутренний ID (`/good/4cbf6c0b791b4bcaa0e1a20bafb0e57c000300010000`).
   - Теперь кэш ИИ (`lqs_ai_cache_v1`), база истории цен (`lqs_price_db_v1`) и фиксатор цен витрины (`lqs_cart_locks_v1`) автоматически связывают оба URL по нормализованному названию товара.

4. **🔒 Безопасность сейфа аккаунтов, чистая смена `localStorage` и точная математика корзины**:
   - Эндпоинты `/api/accounts/*` на локальном сервере `:8765` защищены строгим `CORSMiddleware` и проверкой заголовка `X-LQS-Client: lavka-quality-shield`.
   - При переключении аккаунтов и выходе старые ключи `localStorage` предыдущего профиля предварительно очищаются.
   - В `extractCartItemsFromDOM` исправлен расчёт цены за 1 шт. относительно суммы строки при `qty > 1`.
   - В `addSingleItemOnTab` добавлен честный учёт лимита остатков на складе и поддержка уменьшения количества кнопкой `-`.

## 🚀 Быстрый старт (Windows 11 + Google Chrome)

1. Распакуй архив `lavka-quality-shield-v2.5.2.zip` в постоянную папку.
2. Открой в Chrome `chrome://extensions`, включи **Режим разработчика (Developer mode)** и нажми **Загрузить распакованное расширение (Load unpacked)** -> выбери папку.
3. При необходимости запусти локальный сервер базы цен и кэша через `start_server.bat` (или включи автозапуск через `enable_windows_autostart.bat`).
