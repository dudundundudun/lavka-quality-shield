# 🛡️ Lavka Quality Shield (v2.1.0)

### Личный фильтр качества, КБЖУ-радар и ИИ-ревизор для [Яндекс Лавки](https://lavka.yandex.ru/)

Расширение добавляет в Яндекс Лавку лаконичную однострочную панель прямо под ценой товара, подсвечивает проверенные и забаненные продукты в каталоге, считает честную цену за 1 кг и за 100 г белка, а также умеет искать реальные отзывы в сети через локальный FastAPI-сервер и ИИ.

## ✨ Что нового в v2.1.0

* **Чистый интерфейс на странице**: кнопка и панель диагностики полностью убраны из веб-страницы Лавки и перенесены в окно расширения (`⚙️ Настройки и ИИ` ➔ спойлер `🛠️ Бортовой журнал для ИИ`).
* **Бортовой самописец для ИИ (Flight Recorder)**: расширение автоматически ведёт лог работы всех 8 подсистем (SPA-роутер, парсер DOM/JSON-LD, калькулятор цены/КБЖУ, виджет товара, разметка каталога, защита корзины, база отзывов и ИИ-ревизор). В один клик формируется готовый Markdown-отчёт (включая лог FastAPI-сервера и карту `data-testid`), который можно сразу скормить любому ИИ для дебаггинга.
* **Точный парсер КБЖУ и мультипаков**: исправлен захват калорий вместо граммов белка при нестандартной вёрстке таблицы пищевой ценности, добавлен учёт упаковок вида `2 × 150 г` и флаг `💪 Много белка`.
* **Мгновенный каталог и отсутствие кэша ошибок**: база отзывов кэшируется в оперативной памяти вкладки без лишних чтений `chrome.storage` при скролле, а временные ошибки соединения с ИИ больше не записываются в SQLite-кэш.
* **Удобное управление отзывами**: в спойлере на странице товара появилась кнопка `🗑️ Сброс`, а в попапе расширения — быстрый поиск по базе и удаление отдельных записей кнопкой `×`.

## 🚀 Установка и запуск

1. Открой `chrome://extensions/` в браузере (Chrome / Brave) и включи **Режим разработчика**.
2. Нажми **Загрузить распакованное расширение** и выбери папку с проектом.
3. Для работы поиска отзывов в сети запусти локальный сервер двойным кликом по `start_server.bat` (требуется Python и пакеты из `requirements.txt`).
4. Настройки модели (Gemini Argon `:8083`, DeepSeek API или Ollama) и бортовой журнал для ИИ доступны по клику на иконку расширения ➔ **⚙️ Настройки и ИИ**.
